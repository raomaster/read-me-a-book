# Security Policy

## Supported Versions

Currently, we maintain security updates for the following versions of **read-me-a-book**:

| Version | Supported          |
| ------- | ------------------ |
| Develop | :white_check_mark: |
| Stable  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

As a DevSecOps-focused project, we take security seriously. If you discover a vulnerability, please follow these steps:

1.  **Do NOT open a public issue.** This prevents potential exploitation while we work on a fix.
2.  Send an email to **[TU-EMAIL-AQUI]@gmail.com** (or your preferred contact method).
3.  In the subject line, please include: `[SECURITY] Vulnerability Report - read-me-a-book`.
4.  Include details about the vulnerability (POC, steps to reproduce, impact).

### Our Process
1.  We will acknowledge your report within 48 hours.
2.  We will validate the issue and determine its severity (CVSS scoring).
3.  A fix will be developed and tested in a private branch.
4.  Once patched, we will release a security update and credit you (if desired).

Thank you for helping keep this project secure.
